# CENTRO — Laboratorio Interactivo de Cálculo II

Experiencia educativa en español sobre centroide, centro de masa y centro de gravedad. Convierte los seis ejercicios del Ticket de Salida del folleto académico en laboratorios interactivos guiados por los cuatro pasos de George Pólya.

## Características

- Seis laboratorios, niveles PISA 1–6, con resultados exactos y verificación física.
- Visualizaciones SVG matemáticamente precisas y experimentos separados de los valores oficiales.
- Modo presentación a pantalla completa, navegación por teclado e indicador de progreso.
- Guía ocultable del expositor, fundamentos teóricos y diseño adaptable a proyector.
- Pruebas automatizadas para los seis cálculos críticos.

## Ejecución local

```bash
npm test
npm run serve
```

Abre `http://localhost:4173` en un navegador moderno.

## Atajos

`←` / `→` navegan las etapas; `F` activa pantalla completa; `G` abre la guía; `M` abre el selector; `R` reinicia; `1`–`6` abren un laboratorio.
